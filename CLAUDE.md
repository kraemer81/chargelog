# ChargeLog

PWA for logging and analysing home charging costs of electric vehicles (Svelte 5, TypeScript, Vite, Dexie).

## Language

- **English** for all code, identifiers, code comments, commit messages, documentation (README, docs/, ADRs, glossary) and issues/specs.
- **German** only for user-facing UI text inside the app (the app is German-only, no i18n layer).

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `kraemer81/chargelog` (via `gh`). See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
